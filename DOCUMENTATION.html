1. Project Overview

The CivicPulse Nexus is an enterprise municipal governance and citizen redressal platform. It coordinates workflows across administrative wards and municipal departments, managing grievance dockets, civil service applications, trade licenses, property tax assessments ($12.4M collection volume), and capital expenditure budgets ($47M allocated).

1.1 Core Highlights

  • Public Docket Tracking: Real-time search by docket ID (GRV-... or SR-...) with live audit status and resolution notes.
  • 5 RBAC Portals: Tailored dashboards for Administrators, Department Supervisors, Compliance Auditors, Field Officers, and Residents.
  • Statutory SLA Enforcement: MTTR benchmark compliance monitoring (94.0% statutory rate vs 90.0% standard).
  • Dual Theme Architecture: Primary soft slate-gray light mode with faded municipal watermark and high-contrast dark mode.

2. Tech Stack & Architecture

Layer Technology Why It Was Chosen
Backend Spring Boot 3.2.5 (Java 17) Strong typing, declarative transactions (@Transactional), Spring Security 6, HikariCP pool.
Frontend React 18, Vite 5.4, Vanilla CSS Fast HMR, modular component tree, lightweight production bundle (< 540 KB), zero CSS overhead.
Database Aiven Managed MySQL 8.4 Cloud-hosted relational DB with enforced SSL (sslmode=REQUIRED) and ACID guarantees.
Security Spring Security 6 + Stateless JWT HMAC-SHA256 signed tokens, BCrypt password hashing, and cookie-based refresh tokens.
Hosting Render (Web Service + Static Site) Automated Git continuous deployment with /health diagnostic check.

3. Data Models / Relational Schema

Table Primary Attributes Constraints & Relationships
users id, username, email, password, role, full_name, department_id, ward Stores credentials and RBAC roles. Password hashed with BCrypt. Foreign key to departments.id.
departments id, name, code, head_name, budget_allocated, budget_spent, sla_target_hours Master registry of city departments (Water, Health, Revenue, Roads, Permits, Education).
grievances id, ticket_number, citizen_id, title, category, department_id, ward, status, priority, resolution_notes Grievance complaints. Unique ticket number (GRV-YYYY-XXXX). Status: SUBMITTED → IN_PROGRESS → RESOLVED / WITHDRAWN.
service_requests id, request_number, citizen_id, service_type, department_id, ward, status, sla_days Municipal service applications (SR-YYYY-XXXX).
budget_allocations id, department_id, fiscal_year, allocated_amount, utilized_amount, quarter Treasury allocations and department disbursement tracking.
revenue_transactions id, receipt_number, payer_name, source_type, amount, transaction_date Municipal revenue audit log (Property Tax, Licenses, Utility Fees).
compliance_audit_logs id, user_id, username, action, details, ip_address, timestamp Immutable audit log capturing all mutations, logins, and status transitions.
